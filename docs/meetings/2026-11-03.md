## 로그인 요청

Django는 역할 `do_or_die_server`로 로컬 PostgreSQL `do_or_die`에 접속한다. 비밀번호는 `~/.config/do-or-die/server.env`에 있다.

앱이 카카오 로그인을 먼저 끝낸다. 카카오가 앱에 액세스 토큰을 주고, 앱은 그 토큰을 이 서버로 보낸다. 서버는 그 토큰으로 카카오 사용자 정보 API를 호출해 회원 번호와 이메일을 받는다. 앱이 보낸 회원 번호는 계정 기준으로 쓰지 않는다.

`users.kakao_id`로 행을 찾는다. 없으면 만든다. 이메일은 카카오가 준 경우에만 소문자로 저장한다. 서버는 `users.id`가 들어간 서명 토큰과 계정 키 `id`, `kakaoId`, `email`, `createdAt`을 돌려준다. 로그인 토큰 표는 만들지 않는다.

앱이 이 서버로 토큰을 보내는 연결은 로그인 확인과 목표 API 확인 뒤에 한다.

### 작업 순서

1. 카카오 액세스 토큰을 받는 로그인 주소와 함수를 만든다.
2. 서명에 쓸 비밀 값을 `server.env`에 둔다. `settings.py`와 git에는 넣지 않는다.
3. 받은 토큰으로 카카오 사용자 정보 API를 호출한다.
4. `users.kakao_id`로 행을 찾거나 만든다.
5. 서명 토큰과 계정 키를 응답한다.
6. 서버를 로컬에서 띄운다.
7. 카카오가 발급한 같은 액세스 토큰으로 로그인 요청을 두 번 보낸다. 첫 요청에서 `users` 행이 생기고, 둘째 요청에서는 그 `kakao_id`의 행이 하나인 채로 남는다.
