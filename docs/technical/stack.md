# 클라이언트와 실행 플랫폼

제품 흐름은 [`docs/initial-proposal.md`](../initial-proposal.md)를 따른다. 이 문서는 그 앱을 어디에, 어떤 클라이언트로 실행할지만 다룬다.

## 조건

1. 첫 버전은 휴대폰 앱에서만 실행한다.
2. 이후 같은 제품을 PC에서도 실행한다.
3. 안드로이드와 iOS를 바꿔 가며 실행할 수 있어야 한다.

## 선택

클라이언트는 **Flutter**로 만든다. 언어는 Dart다.

안드로이드와 iOS는 하나의 프로젝트다. 실행 대상 기기만 바꾸면 같은 화면과 같은 목표 흐름이 양쪽에서 돈다. PC는 나중에 이 프로젝트의 데스크톱 대상을 켜서 연다. 목표 입력, 인증 안내, 달성 체크는 그때 다시 짜지 않는다.

첫 버전에서 켜는 대상은 안드로이드와 iOS뿐이다. PC용 빌드, 설치 파일, 데스크톱 레이아웃은 만들지 않는다.

## 플랫폼별 기능

플랫폼마다 달라지는 기능은 공통 화면 밖에 둔다.

| 구분 | 담당 |
| --- | --- |
| 공통 | 목표 입력, AI 인증 응답 표시, 달성 체크 |
| 안드로이드 / iOS | 카메라 촬영, 휴대폰 잠금 |
| 이후 PC | 사진 파일로 인증. 휴대폰 잠금은 PC 기능으로 두지 않는다 |

## 아직 정하지 않은 것

- 서버와 AI 제공자
- 휴대폰 잠금을 앱이 실제로 막을 수 있는 범위. 운영체제 제한이 커서, 기기 전체 잠금과 앱 안에서 지키는 잠금을 구분해야 한다.
